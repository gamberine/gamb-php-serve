# Antigravity

O arquivo `gamb-php-serve.json` e um contrato local para o executor Antigravity reutilizar os mesmos comandos do terminal e do dashboard. Ele nao concede credenciais, nao instala ferramentas e nao cria fallback pago.

A disponibilidade real do Antigravity deve ser verificada no ambiente em que o contrato for carregado. Este repositorio fornece o contrato e os comandos; nao declara a ativacao de um executor externo.
