Manual do produto

Trabalhe localmente com clareza e controle.

O Gamb PHP Serve organiza o caminho entre encontrar um projeto, iniciar PHP e banco, trabalhar no hub e encerrar a sessao sem depender de um painel paralelo.

1. Instalar

Use Git Bash e mantenha PHP CLI ou PHP portatil disponivel.

bash -c "$(curl -fsSL https://raw.githubusercontent.com/gamberine/gamb-php-serve/main/install.sh)"

2. Iniciar

Entre na pasta do projeto. A URL e o hub sao dinamicos.

cd /d/ProjetosWeb/meu-projeto
gamb-php-serve

3. Descobrir

Encontre projetos existentes sem editar os arquivos deles.

gamb-php-discover --root /d/ProjetosWeb --register

4. Banco local

Inicie MySQL/MariaDB diretamente pelos binarios instalados.

gamb-php-db-check
gamb-php-db-start
gamb-php-db-shell --database minha_base

5. WordPress

Copie uma instalacao local para um destino novo e gere configuracao.

gamb-php-wp-install --source /d/site --destination /d/novo-site --db-name novo_site

6. Movimentar

Planeje antes de copiar. O dump do banco e opcional e revisavel.

gamb-php-wp-move --source /d/site --destination /d/novo-site

Seguranca por desenho

  • Loopback local em `127.0.0.1`.
  • Dashboard com acoes conhecidas e parametros escapados.
  • Extensao VS Code sem dependencias npm de runtime.
  • Senha do banco solicitada pelo cliente, sem argumento exposto.
  • Movimentacao WordPress em simulacao antes de qualquer copia.
  • Nenhuma publicacao remota ou sobrescrita implicita.
